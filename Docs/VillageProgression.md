# 마을 점수와 해금 설정

`Assets/Scenes/Village.unity`의 `CanvasDynamic/VillageScore`에 마을 레벨, 점수, 게이지가 연결되어 있습니다.

- 거래 보상은 산소 대신 마을 점수에 더해집니다. 각 Building의 `Village Score Per Trade`에서 조정합니다. 기존 거래 보상 값은 그대로 이관됩니다.
- `CanvasDynamic/VillageScore` 또는 `VillageManagement`를 선택하면 인스펙터의 **마을 점수 / 레벨 설정**에서 1→2부터 8→9까지 **레벨별 게이지 총량**을 직접 지정할 수 있습니다. 임시 기본값은 순서대로 100, 200, …, 800입니다.
- **시작 마을 레벨 / 시작 마을 점수**는 새 저장 또는 마을 진행 초기화 시 적용됩니다. 기존 저장 파일을 불러올 때는 저장된 진행을 유지합니다.
- 실행 중에는 **현재 마을 레벨 / 현재 마을 점수**도 직접 수정할 수 있으며 UI·해금·이머전시에 즉시 반영하고 저장합니다. 점수가 게이지 총량을 넘으면 초과분을 넘기면서 레벨업합니다. 실행 중 생성되는 VillageManagementDebugProxy 인스펙터에서도 같은 설정을 수정할 수 있습니다.
- 레벨업 때 필요한 점수만 차감하고 초과 점수는 다음 레벨에 넘깁니다. 한 거래로 여러 레벨이 오를 수 있습니다.
- 마을 점수가 감소해도 레벨은 내려가지 않으며 점수는 0 아래로 내려가지 않습니다.
- 9레벨에서는 게이지만 숨기고 점수를 계속 표시·누적합니다. 점수는 64비트 정수로 저장합니다.
- 레벨, 점수, 플레이어 구매 내역은 기존 마을 저장 파일에 함께 저장됩니다. 기존 산소·에너지·설치 건물은 유지됩니다.

일반·특별빌딩의 `Required Village Level`은 0일 때 종류에 따른 기본값을 사용합니다. 1~9를 지정하면 해당 값을 사용합니다. Oil 상점의 등록 그룹도 0일 때 등록 순서대로 1, 2, 4, 6레벨을 사용합니다. 터렛은 등록 슬롯 순서대로 1~4레벨에 해금됩니다. 각 터렛의 1~3단계 업그레이드는 같은 슬롯의 해금 조건을 따릅니다.

플레이어 1은 시작 캐릭터입니다. 플레이어 2~5는 레벨 해금 후 Player 상점에서 산소로 구매하며, 구매 후 Play 메뉴에서 선택할 수 있습니다. 가격은 `VillageManagement/Arcade Players`에서 지정합니다. 프리팹 기본 가격은 플레이어 2부터 50, 100, 150, 200입니다.

# 마을회관

씬의 기존 Bank 오브젝트에 `VillageTownHall`을 연결하고 이름을 `VillageTownHall`로 바꿨습니다. 기존 산소 창고 기능은 Bank 컴포넌트가 담당합니다. 회관 충돌체는 몬스터 경로 끝에 배치되어 있습니다.

회관 외형은 현재 씬에 연결되어 있지 않습니다. `VillageTownHall/Level Activations`의 각 항목에 레벨별 `Linked Prefab`을 할당합니다. 씬 오브젝트는 직접 활성화하고, 프리팹 에셋은 달성 시 한 번 생성합니다. 달성한 레벨의 연결 오브젝트는 계속 활성화됩니다. 아직 없는 특별빌딩 3은 제작 후 Building 상점의 `Registered Special Building Prefabs`에 추가하면 기본 8레벨에 해금됩니다.

`Visual Root`에는 피격 때 흔들릴 외형 루트를 지정할 수 있습니다. 미지정 시 회관 전체를 흔듭니다. 피격 시 0.2초 동안 빨간색과 좌우 흔들림을 적용하고 기존 색·위치로 복원합니다. 연속 피격과 비활성화 시에도 원래 상태로 복원합니다.

몬스터의 `Village Score Damage`가 회관에 닿을 때 차감할 점수입니다. 몬스터 한 마리의 충돌 보상은 한 번만 적용하고 기존 사망 처리를 진행합니다.

# 이머전시

마을 레벨업 시 이머전시 난이도를 같은 레벨로 올립니다. `Emergency/Levels`는 0번 항목이 마을 1레벨, 1번 항목이 마을 2레벨에 대응합니다. 각 항목에서 몬스터 종류·수·출현 간격을 설정합니다. 설정한 항목 수보다 마을 레벨이 높으면 마지막 항목을 재사용합니다. 현재 씬에는 기존 1개 항목만 설정되어 있으므로, 레벨별 몬스터 구성을 다르게 하려면 나머지 항목을 추가합니다.
